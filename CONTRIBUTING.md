# Contributing

Birding Pal is shared as a project recap and prototype repository.

Issues and focused pull requests are welcome. Please open an issue before
submitting a larger change so maintainers can confirm the scope.

External contributions may require completion of the OpenAI Contributor License
Agreement before they can be accepted. By contributing, you agree that your
contribution may be licensed under the MIT License used by this repository.

Do not include secrets, API keys, Wi-Fi credentials, private certificates,
personal data, unapproved media, datasets, model weights, or third-party content
in issues or pull requests.
