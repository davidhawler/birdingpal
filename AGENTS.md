# Codex Notes

This repository is a project recap for Birding Pal, not a step-by-step public
build tutorial.

When editing this repo:

- Preserve the README's "what we did" tone.
- Keep Android details in supporting files unless they are necessary to explain
  the technical implementation.
- Do not change the firmware wiring diagram or schematic unless explicitly
  asked.
- Do not add secrets, API keys, Wi-Fi credentials, private certificates,
  personal data, unapproved media, datasets, model weights, or generated build
  artifacts.
- Keep `.env*`, `local.properties`, Gradle caches, and build outputs ignored.
- Run a secret scan and the open-source repo audit before release-oriented
  changes.
